# Toine Fiselier – personal website

Live at https://toinefiselier.github.io/ToineFiselier/

Plain HTML. No build step, nothing to install.

## Files

| File | What it is |
| --- | --- |
| `index.html` | Home page: bio, research interests, contact |
| `publications.html` | Articles, working papers, policy reports, datasets |
| `teaching.html` | Teaching and thesis coaching |
| `cv.pdf` | The CV linked in the menu. Replace this file to update your CV. |
| `photo.jpg` | Profile photo on the home page |
| `style.css` | Fonts, colours and layout for all pages |
| `404.html` | "Page not found". Also sends old links (like `/publications/`) to the new pages. |

## How to edit

1. Open the `.html` file in any text editor and change the text.
2. To check it, double-click the file to open it in your browser.
3. Commit and push to `main`. The site updates within a minute or two.

The menu at the top is copied into each page. If you add a page, add it to the menu in every file (including `404.html`).
